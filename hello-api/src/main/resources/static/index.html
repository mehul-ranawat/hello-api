// about this project

What is Hello API?

A backend REST API — the backbone of modern web apps. When your browser visits a URL, this server receives the request and sends back a response. Think of it as a waiter: you order something, it delivers exactly that.

🚀

REST Architecture

Uses standard HTTP methods (GET, POST) to serve data — the same pattern used by Instagram, Zomato, and every major app.

⚡

Spring Boot 3

Industry-standard Java framework. Auto-configures everything so you write business logic, not boilerplate.

☕

Java 21 LTS

The latest Long-Term Support version of Java — faster, modern syntax, and production-ready for years to come.

📦

Maven Build

Manages all dependencies and builds the project into a single executable JAR file. One command to run anywhere.
