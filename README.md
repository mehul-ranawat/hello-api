# Hello API 🚀

A simple REST API built with Spring Boot 3 + Java 21.

## Endpoints
| Method | URL | Response |
|--------|-----|----------|
| GET | /hello | Hello, World! |

## Run Locally
1. Clone the repo
2. Open in IntelliJ
3. Run `HelloApiApplication.java`
4. Visit `http://localhost:8080/hello`

## Tech Stack
- Java 21
- Spring Boot 3.5.14
- Maven
